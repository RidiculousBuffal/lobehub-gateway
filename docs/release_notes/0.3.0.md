# 0.3.0

## Added

- Unified binary `gateway`: starts both agent gateway and device gateway in a single process
- Root module `go.mod`: imports both sub-modules via `replace` directives and facade files that re-export internal package symbols
- CI workflow: parallel checks for the unified binary and each sub-module on PR and push to master
- CD workflow: manual trigger, cross-compiles linux/amd64 and linux/arm64 binaries, creates GitHub Release
- Environment variables `AGENT_PORT` (default 8787) and `DEVICE_PORT` (default 8788) control each service's listen port in the unified binary; the unified binary does not read `PORT`

## Compatibility

- Both sub-modules remain independently buildable and testable, unaffected by the root module
- Standalone binaries `agent-gateway` and `device-gateway` continue to be provided and behave exactly as in 0.2.0: both read `PORT` (default 8787)
