# 0.3.0

## 新增

- 统一二进制 `gateway`：启动单个进程同时运行 agent gateway 和 device gateway
- 根模块 `go.mod`：通过 `replace` 指令引用两个子模块，经 facade 文件重导出 internal 包符号
- CI workflow：PR 和 push main 时并行检查统一二进制及各子模块的编译与测试
- CD workflow：手动触发，交叉编译 linux/amd64 和 linux/arm64 二进制，创建 GitHub Release
- 环境变量 `AGENT_PORT`（默认 8787）和 `DEVICE_PORT`（默认 8788）分别控制两个服务的监听端口

## 变更

- `agent-gateway-go` 的端口环境变量从 `PORT` 改为 `AGENT_PORT`
- `device-gateway-go` 的端口环境变量从 `PORT` 改为 `DEVICE_PORT`，默认值从 8787 改为 8788

## 兼容性

- 两个子模块仍可独立 build/test，不受根模块影响
- 独立二进制 `agent-gateway` 和 `device-gateway` 继续提供，行为与 0.2.0 一致
